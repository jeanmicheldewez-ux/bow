# Roadmap

## v0.1

- Define reusable module format.
- Use normalized float packets internally.
- Provide graph JSON format and export.
- Include MIDI-like simulator, mock model, Creative Mapper and visualizer.
- Document reuse paths for WATTOO, Midiboy, Dancing5 and Supersets.

## v0.2

- Add module manifest loading.
- Add graph import.
- Add label-based Creative Mapper strategy.
- Add real Web MIDI transport adapter.
- Add audio feature transport using Web Audio.
- Add recording and playback of `DataPacket` streams.

## v0.3

- Add body tracking adapter shape for MediaPipe or similar systems.
- Define skeleton, bone vector and joint angle packet conventions.
- Add Tone.js output adapter.
- Add richer visualizer module examples.

## Later

- Multi-screen and projector routing for WATTOO-style installations.
- Supersets-style preference and preset learning modules.
- Midiboy-style dynamic zone model modules.
- Dancing5 model import/export conventions.
- ESP32 MIDI and sensor adapters.
- Physical puppet output adapters with min/max position, speed limits, acceleration limits, calibration, emergency stop and home position.
